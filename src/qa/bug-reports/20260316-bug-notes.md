# Bug Notes for Tournament Management System

## Bug 1: Unable to create a tournament.
- Severity: High
- Steps to reproduce:
  1. Log in as admin role.
  2. Navigate to "Create Tournament" page.
  3. Fill in tournament details and submit.
- Expected result: Tournament is created and listed on the dashboard.
